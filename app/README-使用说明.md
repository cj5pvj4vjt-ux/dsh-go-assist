# DSH 小V 使用说明（v22 final）

> 一个「按住/一点就说话」的语音助手入口：说话 → 本地识别 → 交给 DSH → 悬浮小窗显示回复。
> 全程不切换前台 App，不打断你正在刷的视频或聊天。

---

## 1. 安装

APK：`out/dsh-assist-v22.apk`（versionCode 22 / versionName `22.0 final`，自签名）

- 安装方式（二选一）：
  1. **root 静默装**：`pm install -r /path/to/dsh-assist-v22.apk`
  2. 手机文件管理器点开 APK → 允许「安装未知应用」→ 安装
- 覆盖安装即可保留配置；签名一致，不会要求卸载旧版。

---

## 2. 首次配置（3 步）

1. 打开「DSH 小V」→ 允许 **悬浮窗** 权限（没有它会退化成全屏界面）。
2. 允许 **麦克风** 权限（没有它没法听你说话）。
3. 点 **「一键接管」**：
   - 有 root / Shizuku：会自动写好电源键相关设置并授予助手角色；
   - 没有 root：只做权限自检，并提示用下面的「快捷磁贴 / 小圆点」唤起。

> 首次启动会有一页极简引导，看过一次不再出现。

---

## 3. 三种唤起方式

| 方式 | 需要 root | 怎么用 |
| --- | --- | --- |
| **快捷设置磁贴**（推荐，免 root） | 不需要 | 下拉通知栏 → 点「编辑/添加图块」→ 把 **DSH 小V** 拖出来 → 之后下拉点一下即唤起 |
| **悬浮小圆点**（免 root） | 不需要 | 设置里打开「常驻小圆点」；胶囊收回后顶部留一个 8dp 小圆点，点它重新聆听 |
| **长按电源键** | **需要** root/Shizuku 写一次 | root 钩子模式：长按 0.3s 起胶囊；系统助手模式：靠框架拉起 AssistActivity |

补充：
- 快捷磁贴点一下 = 直接开始听，不打开任何界面。
- 悬浮小圆点在 `power_mode=root` 且 Shizuku 可用时会自动隐藏（走电源键更顺）；其余情况默认显示。
- 划返回手势或点击窗外，会立刻收回悬浮窗。

---

## 4. 回复在哪看

- 识别出的文字 → 写到 `dsh-inbox/<时间戳>.txt` 交给 DSH；
- DSH 处理时胶囊显示 `DSH 处理中 Ns` 秒表（最多等 180 秒）；
- 回复出现在**同一个悬浮小窗**里，最多显示 10 行，可上下滑动；
- 右下角「展开」可撑到屏幕 60%（停留 30 秒）；碰一下小窗会重置停留计时；
- 失败会红字提示并给「重试」按钮；
- 如果偏好里打开了「结果用 DSH 打开」（默认关），才会整屏切到 DSH。

---

## 5. 重启手机后要做什么

1. **打开 Shizuku**（只有需要「root 钩子 / root 桥 / 长按电源键接管」时才必须；日常用磁贴/小圆点可不开）。
2. 打开「DSH 小V」，看状态卡「电源键模式」：
   - 绿色 = 正常；
   - 琥珀色「无 root，建议用快捷磁贴/圆点」= 用磁贴或小圆点唤起即可。
3. 如果提示设置被重置，点一次「一键接管」或切一次「电源键模式」即恢复。

---

## 6. 回滚 / 卸载

- **回滚到旧版**：直接用旧版 APK 覆盖安装（同签名）；如需彻底干净，先在系统设置里「卸载 DSH 小V」再装旧版。
- **卸载**：系统设置 → 应用 → DSH 小V → 卸载。
- 卸载不会删除这些目录（如需清理可手动删）：
  - `/sdcard/Android/media/com.dshgo.assist/`（overlay.log、last-voice.wav、dsh-inbox/、dsh-outbox/）
  - `/sdcard/Download/DSH-Go/`（root 桥/钩子脚本与日志，仅 root 模式会产生）

---

## 7. 常见问题

- **说话没反应？** 看 `/sdcard/Android/media/com.dshgo.assist/overlay.log`：
  - `asr health fail` → 本地识别服务（127.0.0.1:18080）没起；
  - `asr vad start` 后没有 `asr recorded` → 麦克风被别的 App 占着；
  - `asr vad noise=… threshold=…` 可用来判断环境噪声。
- **悬浮窗突然消失？** v22 已修「重复启动把窗口 removeView 重加」；若仍出现，看日志里是否有 `duplicate start ignored`。
- **长按电源键没反应且会锁屏？** 说明是 root 钩子模式但钩子没在跑；切到「系统助手」或用磁贴/小圆点。
- **想改识别服务地址**：高级区「识别服务」行，点或长按可编辑 endpoint / token。
